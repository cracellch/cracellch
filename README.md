# Hola, soy Alfonso García 👋

Soy **maker** y **programador web**, y hago **robótica educativa** desde la CDMX. Diseño robots con Arduino y ESP32, el software para programarlos y el material con el que niños, niñas y docentes aprenden a usarlos. También desarrollo sitios y plataformas web.

He creado muchas cosas para **[Robodacta](https://robodacta.com.mx)**, y además tengo **mis propios proyectos independientes**. Aquí está solo una parte: todavía me faltan muchos por subir. 🚧

- 🤖 Mi proyecto más grande para Robodacta: **RDA BLOCKS**, programación por bloques en español con simulador 3D y carga por Bluetooth.
- 🧰 Me gusta construir herramientas que ahorran trabajo repetitivo: grabar decenas de Arduinos, renombrar módulos Bluetooth, generar videos tutoriales automáticamente.
- 🌐 Como programador web he hecho una tienda en línea y, para Robodacta, dos plataformas (pronto las agrego aquí).
- 📚 También diseño programas STEAM (de preescolar a primaria), prácticas de clase y talleres.
- 🧠 Trabajo con IA (Claude Code) como asistente de programación. Yo dirijo el producto, la arquitectura y las pruebas con hardware real.

## Proyectos destacados

### [RDA BLOCKS](https://github.com/cracellch/rda-blocks-showcase)

Editor de bloques para robots con Arduino Nano y ESP32-C6. Tiene un simulador 3D que corre el mismo programa que el robot y un firmware propio (una máquina virtual) para cargar en 2 segundos por USB o Bluetooth. Funciona en escritorio, navegador, Android e iPhone.

<a href="https://github.com/cracellch/rda-blocks-showcase"><img src="https://raw.githubusercontent.com/cracellch/rda-blocks-showcase/main/img/simulador-sumo.gif" alt="Simulador 3D de RDA BLOCKS" width="600"></a>

`JavaScript` `Blockly` `three.js` `Electron` `C++` `Web Bluetooth`
